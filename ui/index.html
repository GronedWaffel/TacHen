YOUR EXTENSIONS

Plugins

Upload a .plugin, .prx or .sprx file in Payloads, then register it here. Start a standalone plugin before opening a game, or arm a game module to load automatically for its exact title and version.

Standalone plugins load once per boot. Native modules load once per game instance, with up to eight attempts per game session. Disabling autostart prevents future loads; it does not unload code or undo patches. Close the game to end its modules. Console validation is pending.
