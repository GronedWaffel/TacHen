Support capture

Enable this before reproducing a problem. TacHen keeps startup, operation and selected native receipt evidence for the latest three captures on this console.

Includes firmware, source build, title ID/version, process IDs, numeric stages and error codes. Excludes credentials, file paths, uploaded files and raw game memory. Nothing is uploaded automatically. Disable recording when finished; existing captures remain until cleared.

Enable before restarting TacHen to capture its next startup. A power loss can omit a pending write; older events are bounded. Captures help investigate a failure but do not prove its cause.
